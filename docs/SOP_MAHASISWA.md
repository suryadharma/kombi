# SOP Penggunaan Aplikasi KomBi - Mahasiswa

## 1. Login

1. Buka `http://localhost:9201/login`
2. Masukkan NIM (sebagai username) & Password
3. Klik **Login**

## 2. Dashboard

Setelah login, Anda akan melihat:
- Status judul skripsi
- Progress skripsi
- Event yang akan datang
- Notifikasi

## 3. Mengajukan Judul Skripsi

### Mengajukan Judul Baru
1. Klik menu **Judul Skripsi** → **Ajukan Judul**
2. Isi form:

   **Judul Skripsi:**
   - Judul Skripsi (wajib)

   **Usulan Dosen & Link Surat Tugas:**
   - Pilih Pembimbing 1 (wajib)
   - Masukkan Link Surat Tugas Pembimbing 1 (wajib)
   - Pilih Pembimbing 2 (opsional)
   - Masukkan Link Surat Tugas Pembimbing 2 (wajib jika dosen dipilih)
   - Pilih Penguji Ketua (wajib)
   - Masukkan Link Surat Tugas Penguji Ketua (wajib)
   - Pilih Penguji Anggota 1 (opsional)
   - Masukkan Link Surat Tugas Penguji Anggota 1 (wajib jika dosen dipilih)
   - Pilih Penguji Anggota 2 (opsional)
   - Masukkan Link Surat Tugas Penguji Anggota 2 (wajib jika dosen dipilih)

3. Klik **Ajukan Judul**
4. Status akan menjadi **MENUNGGU** (menunggu verifikasi Kombi)

### Tips Pengisian:
- Gunakan link Google Drive/OneDrive yang bisa diakses
- Pastikan link bisa dibuka tanpa perlu izin tambahan
- Pilih dosen sesuai SK kampus
- Lengkapi semua kolom bertanda *

### Melihat Status Judul
1. Klik menu **Judul Skripsi**
2. Status judul Anda:
   - **MENUNGGU**: Sedang diverifikasi
   - **DITERIMA**: Judul disetujui, dosen sudah ditetapkan
   - **PERLU REVISI**: Harus revisi judul
   - **DITOLAK**: Harus ajukan judul baru

### Mengupdate Link Surat Tugas (Jika Judul Sudah Ada)
1. Jika judul sudah ada, Anda bisa update link surat tugas
2. Ganti link surat tugas yang diperlukan
3. Klik **Simpan Link Surat Tugas**

### Mengedit Judul (Jika PERLU REVISI/DITOLAK)
1. Hubungi Kombi untuk edit judul
2. Atau tunggu instruksi dari Kombi

## 4. Melihat Dosen Pembimbing & Penguji

1. Klik menu **Judul Skripsi**
2. Setelah DITERIMA, dosen yang ditetapkan akan muncul

## 5. Progress Skripsi

### Melihat Timeline Progress
1. Klik menu **Progress**
2. Timeline akan muncul:
   - Seminar Proposal
   - Seminar Hasil
   - Pra-Ujian
   - Ujian Skripsi
   - Kelulusan

### Melihat Nilai
1. Klik pada stage yang sudah selesai
2. Nilai akan muncul (jika diaktifkan oleh Kombi)

### Download PDF Nilai
1. Klik **Download PDF** pada stage
2. PDF berita acara akan didownload

## 6. Jadwal Seminar/Sidang

### Melihat Jadwal
1. Klik menu **Event** atau lihat di Dashboard
2. Jadwal akan muncul:
   - Tipe event
   - Tanggal & waktu
   - Lokasi
   - Dosen penguji

## 7. Profil

### Melihat Profil
1. Klik menu **Profil**
2. Informasi Anda akan muncul

### Mengubah Profil/Password
1. Klik menu **Profil**
2. Klik **Edit Profil** atau **Ubah Password**
3. Update informasi
4. Klik **Simpan**
