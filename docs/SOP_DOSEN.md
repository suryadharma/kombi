# SOP Penggunaan Aplikasi KomBi - Dosen

## 1. Login

1. Buka `http://localhost:9201/login`
2. Masukkan Username & Password
3. Klik **Login**

## 2. Dashboard

Setelah login, Anda akan melihat:
- Mahasiswa yang Anda bimbing
- Mahasiswa yang Anda uji
- Event yang akan datang
- Penilaian yang belum dinilai

## 3. Melihat Mahasiswa Bimbingan

1. Klik menu **Dashboard** atau **Mahasiswa Bimbingan**
2. Daftar mahasiswa bimbingan akan muncul dengan:
   - NIM, Nama
   - Judul Skripsi
   - Progress

## 4. Melihat Mahasiswa Ujian

1. Klik menu **Mahasiswa Ujian**
2. Daftar mahasiswa yang Anda uji akan muncul

## 5. Menilai Mahasiswa

### Melihat Event yang Perlu Dinilai
1. Klik menu **Penilaian** → **Belum Dinilai**
2. Daftar event yang sudah selesai akan muncul

### Mengirim Nilai
1. Klik **Nilai** pada event yang dipilih
2. Isi form penilaian:
   - Nilai setiap komponen (1-100)
   - Catatan (opsional)
   - Rekomendasi (LULUS/TIDAK LULUS)
3. Klik **Simpan Nilai**
4. PDF akan otomatis terkirim ke email (jika diaktifkan)

### Mencetak PDF
1. Setelah menyimpan nilai, klik **Cetak PDF**
2. PDF berita acara akan didownload

### Melihat Riwayat Penilaian
1. Klik menu **Penilaian** → **Riwayat Penilaian**
2. Daftar semua penilaian Anda akan muncul

## 6. Profil

### Melihat Profil
1. Klik menu **Profil**
2. Informasi profil Anda akan muncul

### Mengubah Profil/Password
1. Klik menu **Profil**
2. Klik **Edit Profil** atau **Ubah Password**
3. Update informasi
4. Klik **Simpan**
